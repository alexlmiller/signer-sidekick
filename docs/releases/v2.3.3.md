# Signer Sidekick v2.3.3

- Distributions now check the payout cycle as well as the current roster. A staker who left can still be paid if the chain confirms a remaining entitlement.
- A departure no longer marks confirmed payments as incomplete. Past cycles explain missing evidence separately from payment status.

## Upgrade

Follow the [upgrade and rollback procedure](https://github.com/alexlmiller/signer-sidekick/blob/v2.3.3/docs/operator/operations.md#upgrade) and use `SIDEKICK_IMAGE_TAG=2.3.3`. This release migrates the database to schema 46; restore the pre-upgrade database if rolling back to v2.3.2.

If automatic rewards are enabled, a previously overlooked payment may become eligible on the next scheduled run. To review it first, turn off automatic rewards before upgrading and check **Rewards → Outstanding** afterward.
