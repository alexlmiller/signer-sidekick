# Signer Sidekick v2.3.4

- Recover reward history when a confirmed calculation falls on an indexed half-cycle boundary. Existing sync cursors retry automatically; no database reset is needed.
- Overview now reports sustained reward-history sync failures separately from signer health and shows whether automatic reward runs are off.
- Brief local node stalls and peer lag start as warnings, escalating to critical after five minutes. Signing and transaction safety checks are unchanged.

## Upgrade

Use `SIDEKICK_IMAGE_TAG=2.3.4` and follow [upgrade and rollback](../operator/operations.md#upgrade). No schema migration. Leave automatic runs off until reward history has caught up and you have reviewed outstanding distributions; restoring synchronization can reveal previously missing work. Upgrading does not enable the schedule.
