# Signer Sidekick v2.3.2

- Update fast-uri to 3.1.9 / 4.2.3 and follow-redirects to 1.16.2 to fix their advisories without changing transaction behavior.
- Align build, CI and runtime with Node.js 24.22.1, preserving the existing operator runtime security update.
- One reviewed advisory remains in unused optional wallet dependencies ([#65](https://github.com/alexlmiller/signer-sidekick/issues/65)); no compatibility-breaking overrides.

## Upgrade

Follow the [matched database, protected configuration/key and old-image backup procedure](https://github.com/alexlmiller/signer-sidekick/blob/v2.3.2/docs/operator/operations.md#upgrade).
Select v2.3.2 and `SIDEKICK_IMAGE_TAG=2.3.2`. This release adds no database migration.
Do not replay submissions or initiate transactions to validate the upgrade.
